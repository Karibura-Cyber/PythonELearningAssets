Set คืออะไร?

Set (เซต) คือโครงสร้างข้อมูลในภาษา Python สำหรับเก็บชุดของสมาชิกที่ ไม่ซ้ำกัน และไม่มีลำดับ เหมาะสำหรับงานที่ต้องการกรองข้อมูลซ้ำ หรือทำ Set Operations ทางคณิตศาสตร์

🔮
Unique (ไม่ซ้ำ)
สมาชิกแต่ละตัวใน Set จะไม่ซ้ำกัน ถ้าใส่ค่าซ้ำ Python จะเก็บไว้เพียงหนึ่งเดียวโดยอัตโนมัติ
🔀
Unordered (ไม่มีลำดับ)
Set ไม่มีลำดับ Index ไม่สามารถใช้ my_set[0] ได้ และลำดับการแสดงผลอาจเปลี่ยนไปทุกครั้ง
⚡
Fast Lookup O(1)
การตรวจสอบว่าสมาชิกอยู่ใน Set หรือไม่ (in) ทำได้เร็วมาก เร็วกว่า List มาก
🧮
Set Operations
รองรับ Union, Intersection, Difference, Symmetric Difference เหมือน Set ทางคณิตศาสตร์

ข้อแตกต่างระหว่าง List, Dictionary และ Set

คุณสมบัติList [ ]Dictionary { }Set { }
ลำดับ✅ Ordered❌ Unordered❌ Unordered
ค่าซ้ำ✅ อนุญาตKey ซ้ำไม่ได้ / Value ซ้ำได้❌ ไม่อนุญาต
เข้าถึงด้วย Index✅ list[0]✅ dict["key"]❌ ไม่ได้
วงเล็บ[ ]{ key: value }{ value }
Mutable✅✅✅ (เซตเอง) แต่สมาชิกต้องเป็น Immutable
💡 เมื่อไหรควรใช้ Set? ใช้เมื่อต้องการ (1) กรองค่าซ้ำออก (2) ตรวจสอบการมีอยู่ด้วย in อย่างรวดเร็ว (3) ทำ Set Operations เช่น หาข้อมูลที่ตัดกัน (Intersection) หรือรวมกัน (Union)
Part 1

การสร้าง Set

ใน Python มี 2 วิธีในการสร้าง Set ได้แก่ การใช้วงเล็บปีกกา { } และการใช้ฟังก์ชัน set()

การสร้างด้วยเครื่องหมาย { } (ปีกกา)

นำข้อมูลทั้งหมดใส่ไว้ภายในวงเล็บปีกกา {...} คั่นด้วยเครื่องหมาย comma (,) Python จะลบข้อมูลที่ซ้ำกันออกโดยอัตโนมัติ และลำดับการแสดงผลอาจไม่ตรงกับที่กำหนด เพราะ Set เป็น Unordered

⚠️ ข้อควรระวัง: {} เปล่า ๆ ใน Python หมายถึง Dictionary ว่าง ไม่ใช่ Set ว่าง! ต้องใช้ set() ถ้าต้องการ Set ว่าง

การสร้างด้วยฟังก์ชัน set()

ใช้ set() เพื่อแปลง List, Tuple หรือ String ให้เป็น Set รวมถึงสร้าง Set ว่าง และกรองค่าซ้ำออกจากข้อมูลที่มีอยู่

int / floatตัวเลข
Set สามารถเก็บ int, float ได้ — เป็น Immutable จึงใช้เป็นสมาชิกได้
strข้อความ
String เป็น Immutable จึงเก็บใน Set ได้ ระวัง: set("abc") → {'a','b','c'}
tupleTuple
Tuple เป็น Immutable ใช้เป็นสมาชิกของ Set ได้ แต่ List ไม่ได้ (Mutable)
⚠️ห้ามใช้
List, Set, Dictionary ไม่สามารถเป็นสมาชิกของ Set ได้ เพราะเป็น Mutable

Part 3

การดำเนินการทางคณิตศาสตร์ของ Set (Set Operations)

Set ใน Python รองรับ Operations เหมือนเซตในคณิตศาสตร์ สามารถใช้ได้ทั้ง เครื่องหมาย Operator และ Method

Union (ยูเนียน) — รวมข้อมูลทั้งหมด

การรวมข้อมูลทุกตัวจากทั้งสองเซต ถ้ามีข้อมูลซ้ำกัน จะเก็บไว้เพียงหนึ่งครั้ง ใช้เครื่องหมาย | หรือ method .union()

สูตร: A | B หรือ A.union(B) → สมาชิกของ A รวมกับสมาชิกของ B (ไม่ซ้ำ)

Intersection (อินเตอร์เซคชัน) — ข้อมูลที่ตัดกัน

เลือกเฉพาะข้อมูลที่มีอยู่ในทั้งสองเซต ใช้เครื่องหมาย & หรือ method .intersection()

สูตร: A & B หรือ A.intersection(B) → สมาชิกที่อยู่ใน A และ B พร้อมกัน

เลือกข้อมูลที่อยู่ในเซตแรก แต่ไม่อยู่ในเซตที่สอง ใช้เครื่องหมาย - หรือ method .difference()

⚠️ Difference ไม่ commutative: A - B ≠ B - A ลำดับมีความสำคัญ!

การเปรียบเทียบ Set — Subset & Superset

เราสามารถตรวจสอบความสัมพันธ์ระหว่างสองเซตได้ว่าเป็น Subset (เซตย่อย) หรือ Superset (เซตครอบคลุม) โดยใช้ Method ต่อไปนี้

Methodการทำงานตัวอย่างผลลัพธ์
.issubset(other)ตรวจว่า Set นี้เป็น subset ของ other หรือไม่{1,2}.issubset({1,2,3})True
.issuperset(other)ตรวจว่า Set นี้เป็น superset ของ other หรือไม่{1,2,3}.issuperset({1,2})True
.isdisjoint(other)ตรวจว่าไม่มีสมาชิกร่วมกันเลยหรือไม่{1,2}.isdisjoint({3,4})True
A == Bตรวจว่า Set เท่ากันหรือไม่ (สมาชิกเหมือนกันทุกตัว){1,2} == {2,1}True (ลำดับไม่สำคัญ)
