การเขียนโปรแกรม
เชิงวัตถุ

OOP คือการเขียนโปรแกรมโดยมองสิ่งต่างๆ เป็น "วัตถุ" ที่มีคุณสมบัติและพฤติกรรม ซึ่งได้แรงบันดาลใจจากโลกความเป็นจริง

🧱 Class & Object 🔐 Encapsulation 🌳 Inheritance 🔀 Polymorphism
📚

องค์ประกอบพื้นฐานของ OOP

หัวใจหลักของการเขียนโปรแกรมเชิงวัตถุมี 4 ส่วนสำคัญ

🧱 1. Class & Object

Class คือต้นแบบ (blueprint) ของวัตถุ เปรียบเหมือนแบบแปลนบ้าน ส่วน Object คือสิ่งที่สร้างขึ้นจาก Class เปรียบเหมือนบ้านที่สร้างแล้ว — Object ประกอบด้วย คุณลักษณะ (Attribute) และ พฤติกรรม (Method)

🔐 2. Encapsulation (การห่อหุ้ม)

การซ่อนรายละเอียดการทำงานและข้อมูลภายใน ไม่ให้ภายนอกเข้าถึงโดยตรง ช่วยสร้างความปลอดภัยและป้องกันการแก้ไขข้อมูลที่ไม่ต้องการ

🌳 3. Inheritance (การสืบทอด)

คลาสลูกสามารถ "รับช่วง" คุณสมบัติจากคลาสแม่ได้ ช่วยให้นำโค้ดกลับมาใช้ซ้ำ (reuse) และประหยัดเวลาในการพัฒนา

🔀 4. Polymorphism (การพ้องรูป)

Method ชื่อเดียวกันสามารถทำงานได้หลายรูปแบบ ขึ้นอยู่กับ Object ที่เรียกใช้ ทำให้โปรแกรมยืดหยุ่นและขยายได้ง่าย

💡
OOP ช่วยให้เราจัดระเบียบโค้ดได้ดีขึ้น เปรียบเหมือนการจัดลิ้นชักที่แยกของออกเป็นหมวดหมู่ แทนที่จะกองรวมกัน

🔴 ภาษาเชิงกระบวนการ (Procedural) 🟢 ภาษาเชิงวัตถุ (OOP)
กำหนดขั้นตอนการแก้ปัญหาเป็นลำดับ กำหนดปัญหาเป็นองค์ประกอบ (วัตถุ)

ออกแบบจากล่างขึ้นบน (Bottom-up) ออกแบบเป็นวัตถุ (Object-based design)
แก้ไขยาก เพราะแต่ละส่วนมีความสัมพันธ์กัน แก้ไขไม่กระทบส่วนอื่น เพราะ Object สมบูรณ์ในตัวเอง
นำโค้ดกลับมาใช้ซ้ำได้ยาก Reuse ได้ง่ายผ่าน Inheritance

Class & Object

แม่แบบและสิ่งที่ถูกสร้างจากแม่แบบ

🏗️ Class คืออะไร?

Class คือ ต้นแบบ (Template / Prototype / Blueprint) ของวัตถุ ก่อนจะสร้างวัตถุได้ ต้องสร้าง Class ขึ้นมาก่อนเสมอ เปรียบเหมือน "แบบแปลนบ้าน" ที่บอกว่าบ้านมีกี่ห้อง หน้าตาเป็นอย่างไร

📦 Object คืออะไร?

Object (วัตถุ / Instance) คือสิ่งที่ถูกสร้างขึ้นจาก Class ประกอบด้วย 2 ส่วนคือ คุณลักษณะ (Attribute) และ พฤติกรรม (Method) เปรียบเหมือน "บ้านจริงๆ" ที่สร้างจากแบบแปลนนั้น

# สร้าง Class
class Animal:
    def __init__(self, name, color):
        self.name = name
        self.color = color

    def sound(self):
        return f"{self.name} ส่งเสียงร้อง"

# สร้าง Object จาก Class
lion = Animal("สิงโต", "เหลือง")
elephant = Animal("ช้าง", "เทา")

print(lion.sound())       # สิงโต ส่งเสียงร้อง
print(elephant.name)     # ช้าง

Attribute & Method

คุณลักษณะและพฤติกรรมของ Object

📋 Attribute

สิ่งที่บ่งบอก คุณลักษณะ ของวัตถุ เช่น ชื่อ สี น้ำหนัก อายุ สร้างด้วย self.ชื่อ = ค่า

⚡ Method

สิ่งที่บ่งบอก พฤติกรรม ของวัตถุ เช่น วิ่ง กิน ร้องเพลง สร้างด้วย def ชื่อ(self):

employee.py 
class Employee:
    # Constructor — เรียกอัตโนมัติตอนสร้าง Object
    def __init__(self, name, salary, age):
        self.name = name       # Attribute: ชื่อ
        self.salary = salary   # Attribute: เงินเดือน
        self.age = age         # Attribute: อายุ

    # Method: คำนวณโบนัส
    def get_bonus(self):
        return self.salary * 0.1

    # Method: แสดงรายละเอียด
    def display(self):
        print(f"ชื่อ: {self.name}")
        print(f"เงินเดือน: {self.salary:,} บาท")
        print(f"โบนัส: {self.get_bonus():,} บาท")

    # Destructor — เรียกตอน Object ถูกทำลาย
    def __del__(self):
        print(f"ลบ {self.name} แล้ว")

# สร้าง Object
emp = Employee("สมชาย", 25000, 28)
emp.display()

Class Variable vs Instance Variable

ตัวแปรสองประเภทภายใน Class

🏛️ Class Variable

ตัวแปรที่ใช้ร่วมกันทุก Object ในคลาส ไม่ต้องสร้าง Object ก็เข้าถึงได้ เรียกอีกชื่อว่า static attribute

👤 Instance Variable

ตัวแปรที่อยู่ใน Object แต่ละตัว แต่ละ Object มีค่าของตัวเอง ต้องสร้าง Object ก่อนจึงเข้าถึงได้

variables.py 
class Dog:
    species = "Canis familiaris"  # Class Variable
    count = 0                       # Class Variable

    def __init__(self, name):
        self.name = name  # Instance Variable
        Dog.count += 1

# เข้าถึง Class Variable โดยไม่สร้าง Object
print(Dog.species)   # Canis familiaris
print(Dog.count)     # 0

d1 = Dog("บัดดี้")
d2 = Dog("แม็กซ์")

print(Dog.count)     # 2 — นับจำนวน Object
print(d1.name)       # บัดดี้

Encapsulation

การห่อหุ้มข้อมูลและซ่อนรายละเอียดการทำงาน

🔒 Encapsulation คืออะไร?

กระบวนการ ซ่อนรายละเอียดการทำงาน และข้อมูลภายใน ไม่ให้ภายนอกเข้าถึงโดยตรง ทำให้ภายนอกไม่สามารถแก้ไขข้อมูลได้ตามใจชอบ ช่วยสร้างความปลอดภัยให้ข้อมูล เหมือนกับบัตรประชาชนที่เห็นแค่ข้อมูลบางส่วนเท่านั้น

public

ใครก็เข้าถึงได้ ไม่มี prefix พิเศษ


self.name
_protected

เข้าถึงได้เฉพาะคลาสตัวเองและคลาสลูก


self._name
__private

เข้าถึงได้เฉพาะคลาสตัวเองเท่านั้น


self.__name
encapsulation.py 
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner          # public
        self._bank = "KBank"        # protected
        self.__balance = balance    # private — ซ่อนยอดเงิน!

    # Getter — ดึงค่า
    def get_balance(self):
        return self.__balance

    # Setter — กำหนดค่า (พร้อม validation)
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return f"ฝากเงิน {amount:,} บาท สำเร็จ"
        return "จำนวนเงินไม่ถูกต้อง"

acc = BankAccount("สมชาย", 10000)

# เข้าถึงผ่าน Getter ได้
print(acc.get_balance())  # 10000

# ❌ เข้าถึงโดยตรงไม่ได้!
# print(acc.__balance)  → AttributeError!

Inheritance

การสืบทอดคุณสมบัติจากคลาสแม่สู่คลาสลูก

🧬 Inheritance คืออะไร?

การสร้างคลาสใหม่โดย รับเอาคุณสมบัติ จากคลาสที่มีอยู่แล้ว คล้ายกับที่ลูกรับลักษณะจากพ่อแม่ ข้อดีคือสามารถ นำโค้ดกลับมาใช้ซ้ำ (reuse) ได้ ไม่ต้องเขียนใหม่ทั้งหมด

inheritance.py 
# คลาสแม่ (Superclass)
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def get_salary(self):
        return self.salary

    def display(self):
        print(f"ชื่อ: {self.name}, เงินเดือน: {self.salary:,}")


# คลาสลูก (Subclass) — สืบทอดจาก Employee
class Programmer(Employee):
    def __init__(self, name, salary, experience):
        super().__init__(name, salary)  # เรียก constructor แม่
        self.experience = experience

    def overtime(self):
        return self.salary * 0.2      # ค่าล่วงเวลา

    # Override method ของแม่
    def display(self):
        super().display()              # เรียก display ของแม่
        print(f"ประสบการณ์: {self.experience} ปี")

# สร้าง Object
dev = Programmer("อาร์ม", 45000, 3)
dev.display()
print(f"ค่าล่วงเวลา: {dev.overtime():,}")

บทเรียน Polymorphism
🔀

Polymorphism

การพ้องรูป — Method เดียวกัน ทำงานหลายรูปแบบ

🎭 Polymorphism คืออะไร?

Poly (หลากหลาย) + Morphism (รูปแบบ) = การที่ Method ชื่อเดียวกันสามารถทำงานได้แตกต่างกัน ขึ้นอยู่กับ Object ที่เรียกใช้ เช่น คำว่า "กา" มีหลายความหมาย ขึ้นอยู่กับบริบท

🔁 Overriding

คลาสลูก เขียนทับ Method ของคลาสแม่ ชื่อ Method เหมือนกัน แต่ทำงานต่างกัน (ผลจาก Inheritance)

➕ Overloading

Method ชื่อเดียวกัน ในคลาสเดียวกัน รับ argument ต่างกัน (ผลจาก Polymorphism) — Python ใช้ default args แทน

polymorphism.py 
class Shape:
    def draw(self):
        print("วาดรูปทรงทั่วไป")

    def area(self):
        return 0


class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def draw(self):               # Override!
        print(f"วาดวงกลม รัศมี {self.radius}")

    def area(self):               # Override!
        return 3.14 * self.radius ** 2


class Rectangle(Shape):
    def __init__(self, w, h):
        self.w = w; self.h = h

    def draw(self):               # Override!
        print(f"วาดสี่เหลี่ยม {self.w}x{self.h}")

    def area(self):
        return self.w * self.h


# Polymorphism ในทางปฏิบัติ
shapes = [Circle(5), Rectangle(4, 6), Circle(3)]

for shape in shapes:
    shape.draw()               # Method เดียว ทำงานต่างกัน!
    print(f"พื้นที่: {shape.area()}")
