โค้ดตัวอย่าง

class Cat:
    # __init__ คือ constructor — รันอัตโนมัติเมื่อสร้าง object
    def __init__(self, name, age, color):
        self.name  = name
        self.age   = age
        self.color = color

    def meow(self):
        return f"{self.name} says: Meow! 🐱"

# สร้าง Object จาก Class
whiskers = Cat("Whiskers", 3, "orange")
midnight  = Cat("Midnight",  1, "black")

__init__ คือ constructor — ฟังก์ชันพิเศษที่ Python เรียกอัตโนมัติทุกครั้งที่สร้าง object ใหม่

Encapsulation

Encapsulation คือการซ่อนรายละเอียดภายในของ object และเปิดเผยเฉพาะสิ่งที่จำเป็น ผ่าน public interface

🔒 Public vs Private

✅ Public — เข้าถึงได้จากภายนอก
self.name    → account.name
deposit()   → account.deposit(500)
get_balance() → account.get_balance()
🔒 Private — เข้าถึงได้เฉพาะภายใน class
self.__balance    → ❌ account.__balance (ERROR)
self.__pin       → ❌ ห้ามเข้าถึงโดยตรง
🔑 ขึ้นต้นด้วย __ (double underscore) = private  |  ไม่มี underscore = public

โค้ดตัวอย่าง — บัญชีธนาคาร

class BankAccount:
    def __init__(self, owner, initial):
        self.owner    = owner           # public
        self.__balance = initial         # private 🔒

    def deposit(self, amount):         # public method
        if amount > 0:
            self.__balance += amount
            return f"ฝาก {amount} บาท ✅"

    def get_balance(self):             # getter
        return self.__balance

Inheritance

Inheritance ช่วยให้ class ลูก (child) สืบทอด attributes และ methods จาก class แม่ (parent) ได้ ลดการเขียนโค้ดซ้ำ

🌳 แผนภูมิ Inheritance

โค้ดตัวอย่าง

class Animal:                          # Parent class
    def __init__(self, name, age):
        self.name = name
        self.age  = age

    def breathe(self):
        return f"{self.name} หายใจ... 🫁"

class Dog(Animal):                     # Child class
    def __init__(self, name, age, breed):
        super().__init__(name, age)      # เรียก parent __init__
        self.breed = breed

    def bark(self):
        return f"{self.name}: Woof! 🐕"

buddy = Dog("Buddy", 4, "Golden Retriever")
print(buddy.breathe())  # สืบทอดจาก Animal
print(buddy.bark())     # method ของ Dog เอง

Polymorphism

Polymorphism (พหุสัณฐาน) คือความสามารถที่ objects ต่างชนิดกัน ตอบสนองต่อ method เดียวกัน (speak()) ในแบบของตัวเอง

🔊 Hover เพื่อฟังเสียงสัตว์

🐄

โค้ดตัวอย่าง

class Animal:
    def speak(self): pass          # Base method

class Dog(Animal):
    def speak(self): return "Woof! 🐕"

class Cat(Animal):
    def speak(self): return "Meow! 🐱"

class Bird(Animal):
    def speak(self): return "Tweet! 🐦"

# Polymorphism ในการทำงาน
animals = [Dog(), Cat(), Bird()]
for a in animals:
    print(a.speak())   # method เดียว → ผลลัพธ์ต่างกัน ✨
